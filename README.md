Cardiovascular Disease Prediction using Machine Learning
📌 Project Overview
Cardiovascular disease is one of the leading causes of death worldwide. This project aims to predict the presence of heart disease using Machine Learning techniques. The project involves data preprocessing, exploratory data analysis (EDA), data visualization, feature correlation analysis, and training multiple machine learning models to identify the best-performing algorithm.

🎯 Objectives
- Perform data preprocessing and cleaning
- Analyze the dataset using visualization techniques
- Generate correlation matrix of features
- Train and evaluate multiple machine learning models
- Compare model accuracies
- Build the best predictive model for heart disease detection

📂 Dataset
The dataset used for this project contains various medical attributes related to cardiovascular health such as:
- Age
- Gender
- Height
- Weight
- Blood Pressure
- Cholesterol
- Glucose
- Smoking Habit
- Alcohol Intake
- Physical Activity
- Cardiovascular Disease Status

🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

🤖 Machine Learning Algorithms Used
The following Machine Learning models are implemented and compared:
1. Logistic Regression (LR)
2. K-Nearest Neighbors (KNN)
3. Decision Tree (DT)
4. Random Forest (RF)
5. Support Vector Machine (SVM)

📊 Exploratory Data Analysis (EDA)
The project includes:
- Count plots
- Histograms
- Distribution plots
- Correlation heatmap
- Feature relationship analysis

🔥 Data Preprocessing Steps
- Handling unnecessary columns
- Converting age from days to years
- Checking missing values
- Feature scaling using StandardScaler
- Train-Test splitting

📈 Model Evaluation
Each model is evaluated using:
- Accuracy Score
- Confusion Matrix
- Classification Report
The best-performing model is selected based on the highest accuracy.

▶️ How to Run the Project
Step 1: Install Required Libraries
pip install pandas numpy matplotlib seaborn scikit-learn
Step 2: Run the Python File
python cardiovascular_prediction.py

Output
The project generates:
Data visualization graphs
Correlation heatmap
Confusion matrices
Accuracy comparison chart
Best model prediction result

Project Outcome
This project demonstrates how Machine Learning can be used in the healthcare domain to predict cardiovascular disease efficiently and accurately using patient medical data.
